# space-ppi-explorer
a space ppi explorer

aka interactome flight deck

## Multiplayer

Enter a room code on the launch screen (or open `index.html#room=CODE`) to fly with others. Uses PeerJS (WebRTC) with the free PeerJS signaling server; pilots form a full mesh, see each other's ships and tracers, and share mapped proteins. Everyone in a room gets the same network (seeded by the room code). Players behind strict NATs may need a TURN server.
